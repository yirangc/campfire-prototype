# Icons

These files are generated by `node scripts/figma/build-icons.mjs` from the vector data of the Figma icon components (file M4alZ0UMg6muqKn7l2WaXW, nodes 12:12143 to 12:12167). Don't edit them by hand.

Figma describes these icons as screenshot-derived reconstructions, not original Campfire artwork.

- `{name}.svg` is the 24 px canvas.
- `{name}-{16,14,12,10}.svg` scale the geometry and keep the 1.5 px stroke, as Figma's small instances do.
- Strokes use `currentColor`. The Icon component colors them with color/text/secondary.
